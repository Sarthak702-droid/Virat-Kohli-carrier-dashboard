🏏 Virat Kohli Career Data Analysis Dashboard (Using Power BI)
📌 Project Objective

To analyze Virat Kohli’s international cricket career in terms of centuries, half-centuries, run distribution across nations, and yearly performance to uncover patterns in his consistency and dominance in international cricket.
📂 Dataset Used

    Source: Compiled dataset from Cricbuzz/ESPNcricinfo (CSV/Excel format)

    Contains: Match-wise run records, opponents, years, and run types (30+, 50s, 100s)

📊 Key Metrics (KPIs)

    Total Centuries (100s): 77

    Scores above 30: 270

    Half Centuries (50s): 129

    Total Matches Played: 254

    Total Innings Played: 516

📈 Visual Insights

    Top Performances by Country:

        Highest number of runs scored against:

            Australia, England, West Indies, Sri Lanka, South Africa

    Lowest Performances:

        Struggled most against:

            Ireland, Afghanistan, Netherlands, Scotland, U.A.E.

    Year-wise Performance Trend:

        Peak run-scoring period: 2016–2018

        Dip observed post-2020

    Run Count Distribution (Donut Chart):

        Australia: 16.67%

        England: 17.65%

        West Indies: 18.95%

        Others: Remaining % split among 10+ teams

⚙️ Tools & Techniques

    Power BI for visualization

    Data Cleaning in Excel

    Custom slicers for year selection and filter-by-opponent

    Multiple chart types: Donut, Column, Line

🧠 Insights & Takeaways

    Virat Kohli maintains remarkable consistency with a near-equal split of 50s and 100s.

    Shows top performance in high-pressure series (e.g., Australia/England tours).

    Needs strategic preparation for Associate Nations where performances dip (possibly fewer matches).

    Strongest run-making form observed in mid-2010s.

✅ Final Conclusion

Virat Kohli’s performance analysis reaffirms his status as a modern-day legend. These insights help cricket analysts, selectors, and fans understand the patterns behind his excellence and areas where he can be more consistent.
